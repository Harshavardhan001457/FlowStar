# Phase 8 fixed experiment design

The fixed evaluation preserves the existing TCP NewReno workload as
`tcp_control` and adds a separate rate-controlled UDP workload as
`udp_stress`. All outputs are written under
[`results/phase8_fixed/`](../results/phase8_fixed/).

## TCP control

The control uses three TCP NewReno BulkSend flows, a 5 Mbps bottleneck, a
100-packet limit, a 20-second simulation, and a 1-to-19-second sender
interval. Baseline uses a fixed-assignment QueueDisc, DQA uses the dynamic
assignment policy, and hybrid uses the same QueueDisc with two dedicated
resources.

## UDP stress

The stress workload uses ten simultaneous UDP OnOff flows, each configured for
500 Kbit/s, for a configured total offered rate of 5 Mbit/s. The bottleneck is
2 Mbps, the queue limit is 5 packets, and the simulation runs for 30 seconds
with senders active from 1 to 29 seconds. Packet size, topology, routing,
access links, delays, seed, and run number remain identical across the
configurations.

UDP is generated by actual `OnOffApplication` instances and received by
`PacketSink` applications. `flow_statistics.csv` records actual FlowMonitor
transmitted bytes and application-received bytes; configured offered rate is
recorded separately in metadata.

The UDP matrix contains:

- Baseline with fixed QueueDisc assignment.
- DQA-only.
- Hybrid with 10 dedicated resources.
- Hybrid with 3 dedicated resources.
- Hybrid with 1 dedicated resource.

## Queue layers and drops

The physical bottleneck queue is the router-to-router
`PointToPointNetDevice::Queue`. DQA and hybrid additionally install a root
`DynamicQueueAssignmentDisc` with internal logical queues. The root QueueDisc
drop trace is distinct from physical device drops and internal logical queue
drops:

- `physical_queue_drops.csv`: physical NetDevice `Drop`.
- `queuedisc_root_drops.csv`: root QueueDisc `Drop`, including
  `DropBeforeEnqueue`.
- `internal_queuedisc_drops.csv`: internal logical queue `Drop`.

FlowMonitor `lost_packets` is reported separately and is not substituted for
any queue-drop count.
